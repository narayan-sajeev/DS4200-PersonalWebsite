About Me

I am an undergraduate student studying Data Science and Business Administration with a Concentration in Finance. A lot of my coursework involves working with numbers and writing code to visualize datasets. I have taken classes to learn how to use Python and SQL to analyze data. I enjoy studying how data analysis can be applied to solve business problems and help make finance decisions.

Outside of analysis, I hope to learn more about how insights can be effectively communicated so that people can make the right decisions. Large datasets are usually difficult to interpret, so learning how to use visualizations is important. In my classes, I'm learning about how to use HTML and CSS to create websites that display charts online. In the future, I hope to work in roles where I can apply my quantitative background to finance problems. When I'm not in class or studying, I enjoy spending time working out at the gym, taking photos around the city, and hanging out with friends. I built this website for my homework to show proficiency with web design.
